# 👗 Lehenga Rental Website - PRD

## 📌 Product Overview
Ek online platform jaha users designer lehenga browse, rent aur return kar sake. Platform ka goal hai affordable fashion provide karna bina purchase kiye.

## 🎯 Objectives
- Users ko high-quality lehenga rent karne ka option dena
- Easy booking & return system
- Secure authentication system
- Admin dashboard for inventory management

## 👥 Target Users
- Brides / wedding attendees
- College students (events, fest)
- Fashion-conscious users on budget

## 🔑 Core Features

### 1. Authentication
- Register/Login
- JWT + Cookies based auth

### 2. User Features
- Browse lehenga collection
- Filter (price, size, color)
- View product details
- Add to cart / wishlist
- Rent booking (select dates)
- Order history

### 3. Admin Features
- Add/Edit/Delete lehenga
- Manage inventory
- View orders
- Approve/Reject bookings

### 4. Rental Flow
1. User selects lehenga
2. Choose rental dates
3. Checkout
4. Payment (future integration)
5. Delivery + Return

### 5. Notifications (optional future)
- Booking confirmation
- Return reminder

## 📊 Success Metrics
- Number of rentals
- User retention
- Conversion rate

## ⚠️ Constraints
- Initial version without payment gateway
- Manual return tracking

## 🚀 Future Scope
- Payment integration (Razorpay)
- Reviews & ratings
- AI-based recommendations
